# Rattil: notes for contributors and coding agents

Expo SDK 58 / React Native 0.88 Android app. Read the versioned Expo docs (https://docs.expo.dev/versions/v58.0.0/)
before touching Expo APIs; they change between SDKs.

- `android/` and `ios/` are generated by `npx expo prebuild` and git-ignored. Configure native behaviour in
  `app.json` and `plugins/`.
- Navigation is deliberately minimal (one screen plus modals), so there is no router.
- Never edit the Quran text. `src/data/generated/quran-text.json` is a verbatim Tanzil copy; regenerate it with
  `scripts/fetch-sources.sh` + `scripts/build-quran-data.mjs`, which validate the layout.
- Highlights and mistake marks are drawn around words, never by changing a word's text.
- Before finishing: `npx tsc --noEmit`.
